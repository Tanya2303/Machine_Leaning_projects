## Selection rationale

Decision Tree’s weighted F1 tied the top cross-validation results, so the one-standard-error rule favored the simpler, easier-to-inspect tree. This split produced 1.000 accuracy, weighted F1, and ROC-AUC on the test set. These unusually high scores are specific to this dataset and split, not evidence of real lending performance. The saved pipeline accepts raw dataset inputs and calculates total assets and loan-to-income/assets ratios internally. The target mapping is recorded in `run_summary.json`.
