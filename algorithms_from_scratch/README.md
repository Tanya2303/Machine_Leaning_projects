# Algorithms from scratch

The NumPy code in `implementations.py` is for understanding core mechanics. It includes batch Gradient Descent, Linear Regression, binary Logistic Regression, KNN classification/regression, K-Means, a numeric CART Decision Tree classifier using Gini impurity, Gaussian Naive Bayes, and PCA by SVD. Scale features before distance-based or gradient-based methods. These compact versions omit production safeguards and should be compared with scikit-learn on real tasks.
